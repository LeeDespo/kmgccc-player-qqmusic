# QQMusic 1.2.0

[kmgccc_player](https://github.com/kmgcc/kmgccc_player) 的 QQ 音乐在线音源补丁。
本版**验证过的上游版本：[2.3.4](https://github.com/kmgcc/kmgccc_player/releases/tag/v2.3.4)**
（补丁基线 `e708a621`）；上游再前进后需要重新迁移并验证，本补丁包只对它记录的基线成立。

## 附件

| 附件 | 说明 |
|---|---|
| `kmgccc_player-2.3.4+QQMusic.1.2.0-arm64.dmg` | 已经打好本补丁的应用（Apple Silicon，macOS 26+，ad-hoc 签名，首次打开需放行一次） |
| `…-patch.tar.gz` | 补丁包：自己从上游构建，或把功能搬到别的上游版本 |
| `…-component.tar.gz` | 数据组件包（`qqmusic-helper-next` + `aria2-next` + 许可证 + 替换说明），版本由 lock 锁定 |

## 新增

- 设置页里每个组件各自带一个「更新组件」按钮，分别指向 HelperNext 与 Aria2 Next **自己的** Release 页面，
  替换步骤按组件分别列出。

## 修复

- 在线页空白（重发修复）：上游给全窗口宿主新加的判定只认本地主页——宿主在 AppKit 层被设成隐藏，
  在线根要么不被构造、要么被画成透明且不可点。现在「宿主画什么」只有一个判定，可见性与命中都跟随它。
  表现是"页面空白、刷新无效"，而设置窗口一切正常。
- 迁移到上游 2.3.4 之后的 `main`：30 个上游提交与集成的冲突逐处解决，包含几处 git 看不出来的语义冲突
  （上游新增入口调用本 fork 删除的旧客户端、工程文件脚本阶段对象 ID 撞车、导入管线新增返回类型、
  枚举新增分支、动画参数改名、提示挂起新增原因）。
